# Model Console

콘솔은 JSON 덤프 대신 모델별 읽을 수 있는 텍스트를 출력한다. 실제 반환값을 표시 형식만 바꾸며 존재하지 않는 값·점수를 만들어 채우거나 수치를 반올림하지 않는다.

| 대상 | 표시 |
| --- | --- |
| 라우터 | 원본 의도·Operation·각 점수·종합 신뢰도·실행 의도, 업무/단계/체크포인트/기한/우선순위/이름·요약/설명, Span 원문과 위치, 생성 종료 여부를 항목별 줄로 표시 |
| 출력 모델 | 최종 생성 텍스트를 따옴표·이스케이프 없이 표시 |
| 감정 모델 | 실제 긍정 확률 |
| STT | 확정된 최종 인식 텍스트와 실제 Confidence만 |
| VAD | 프레임·reset 응답 출력 안 함 |
| TTS | PCM·base64·오디오 chunk·버퍼·텐서 출력 안 함. 실제 발화 문장은 DeskPet 텍스트로 표시 |

업무 결과는 상태·동작·대상·오류·결과를 들여쓰기로 정리한다. route는 실제 선택 경로만 표시한다. 입력·발화 문장은 원문을 유지한다. 객체 내부의 구조화된 오류 사유·시간 기록 등도 JSON 문자열 그대로 노출하지 않고 항목으로 펼친다. 비활성 head의 실제 null과 빈 결과는 구분하고 임의 숫자 기본값을 추가하지 않는다.

STT partial·토큰 중간값과 텍스트로 볼 수 없는 미디어 데이터는 계속 차단한다. 설정 설명·준비 완료 등의 임의 안내는 출력하지 않는다. 출력 큐와 종료 시 flush 동작은 유지한다. 테스트·빌드·모델 실행은 수행하지 않는다.
